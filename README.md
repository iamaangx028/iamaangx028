# iamaangx028 — Personal Portfolio

**🌐 Live:** [iamaangx.me](https://iamaangx.me)

A static personal portfolio for Rokkam Vamshi (Aang), a security researcher.
Plain HTML/CSS/vanilla JavaScript — no build step, no framework.

## Run locally

The blog uses `fetch()`, so serve over HTTP (not `file://`):

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

Open `/` for the main portfolio, or `/Blog/` for the blog.
